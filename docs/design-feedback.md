## #4 Quizlet-style redesign — how our features map

Quizlet's study modes are Flashcards, Learn, Test and Match ([Quizlet help: Studying](https://help.quizlet.com/hc/en-au/articles/360030841732-Studying-on-Quizlet)). Learn mixes question types and adapts; Test is an auto-generated mix of written, multiple-choice and true-or-false questions; Match is a timed matching game ([Tech & Learning](https://www.techlearning.com/how-to/what-is-quizlet-and-how-can-i-teach-with-it)).

| Quizlet pattern | Study Buddy today | Adaptation |
|---|---|---|
| **Set page**: title + term count, a swipeable flashcard preview at the top, big study-mode buttons, then the term list | Deck screen with tabs (Flashcards · Notes · Questions, #2) | Deck header (title, subject, counts) → flashcard **preview carousel** → **study-mode tiles** ("Flashcards", "Quiz", "Test", maybe "Match") → the tabbed lists below. |
| **Flashcards**: big card, tap to flip (animated), **swipe right = know, swipe left = still learning**, counters for both, progress bar, shuffle, end screen "keep reviewing the ones you're still learning" | Flashcard view: tap to flip + Again/Hard/Good/Easy buttons | Big full-width card with a **flip animation**; **swipe right = Good, left = Again** (FSRS ratings), optional Hard/Easy buttons kept small; "Still learning N / Know N" counters; round-end screen with "Review the N still learning". |
| **Learn**: one question at a time, mixed types, **feedback banner slides up** (green "Great job!" / red with the right answer) + Continue, progress toward mastery | Study screen: one question per screen, feedback card below the question | Bottom **feedback sheet** (green/red) with the answer, explanation, source page and a big **Continue** button; segmented progress bar. This is our "Quiz" (FSRS-scheduled). |
| **Test**: pick question types + count, answer all, then a **results screen** (score ring, what you missed, retake) | Session summary (score, missed list) | Add a "Test" mode: choose quiz types + number of questions, no feedback until the end, results screen with a **score ring** and missed questions with explanations. Not FSRS-scheduled (practice only). |
| **Match**: timed tap-to-match terms and definitions | — (new) | Optional fun mode using flashcards (term ↔ meaning), fully offline. Decide whether it's in v1. |
| **Home**: "Recents" set cards, prominent create button | Home: due card + deck list + "Add lecture" | Due-today hero card, **recent decks as rounded cards** with counts and a small progress indicator, bigger "+" create button. |
| **Look**: clean light background, white rounded cards, bold headings, one strong accent, lots of spacing, dark mode | Material 3 indigo, default spacing | Our own palette (keep indigo or pick a new accent), white elevated cards with large radius, bolder type scale, more spacing, matching dark theme. |
